## Shape

The file is not comma-separated CSV. Every record is one line with six fields
split on U+203D INTERROBANG (`‽`):

| column | notes |
|---|---|

| url | absolute page URL, never empty |
| title | free text |
| tags | comma-separated labels, case-sensitive, not normalized |
| upload_date | mostly `DD/MM/YYYY`, often blank |
| video_id | site-local id, never empty in this dump |

- 23,686,411 data rows, plus one header line.
- 0 malformed rows: every line decoded as UTF-8 and had exactly six fields.
- Scan time on this machine: 850.5 s, about 7.3 MiB/s.

## Tags

Tags are not a controlled vocabulary. The same idea is stored under several
strings (`amateur` 4,578,478 and `Amateur` 1,929,576; `blowjob` and
`Blowjob`; `teen` / `Teen` / `teens`). Any downstream count should
lowercase and fold separators (`big-tits`, `big tits`, `Big Tits`) before
ranking. The top raw strings are dominated by amateur, blowjob, hardcore,
HD, teen, cumshot, and anal.

A large tail of rare tags (2.1 million distinct strings, while a row averages
only ~13 tags) means many labels occur once. Treat rare tags as noise unless
they are normalized.
